# Affiliate spots: hidden AFF markers in the drafts

Every product spot in the 11 guides carries a hidden HTML comment right after the product name:
`<!-- AFF:program:product-slug -->`. Nothing renders on the page and no product name is a link yet.
Program priority is Amazon; all markers are `amazon` for now (no product is a clearly store-specific item).
When an affiliate tag arrives, search the guide for the marker and turn that product name into a
disclosed paid link (or set the item's `url:` in front matter). Search all guides: `grep -rn "AFF:amazon:<slug>" _drafts`.

Section column: tools / materials / products = front matter list (What you'll need, Gear box); body = step text.
